# Changelog

## v1.1 — 2026-11-23

- UI baru untuk seluruh halaman: Dashboard, Wi-Fi, Jaringan, Hotspot,
  Pengaturan, dan Tentang.
- Bahasa Indonesia, English, dan otomatis mengikuti locale sistem.
- Halaman Tentang dirapikan, credit **DikNom** ditambahkan, dan informasi
  hardware/driver/distro ditampilkan.
- Deteksi interface lintas distro: NetworkManager + fallback sysfs.
- Deteksi driver, chip Wi-Fi, dan dukungan AP secara otomatis.
- Hotspot: AP Wi-Fi, client list, kick, blacklist, batas client, dan konfigurasi
  SSID/password/keamanan.
- Uplink hotspot sementara dibatasi ke LAN/USB untuk kestabilan host.
- Installer lintas distro (`install.sh`), uninstaller, desktop entry, ikon,
  README, serta dokumentasi kontribusi.
- Screenshot repo disanitasi: IP, SSID, MAC, hostname, dan nama koneksi
  diganti dengan data generik.

## v1.0 — 2026-11-23

- Rilis awal panel jaringan DikNom.
